## Purpose

Performs binary search.

## Time Complexity

$O(\log n)$

## Usage

`dichotomy(lower_bound, upper_bound, λ:int -> bool lambda)` returns the minimum number for which λ is true. The search range is passed as a half-open interval, and if no evaluation is true within the interval, the upper bound is returned.
For example

```cpp
dichotomy(0, 100, [](int n){
  return 50 < n;
});
```

returns 51, which is the minimum n satisfying $ 50 < n $.

## Implementation

```cpp
int dichotomy(int ng, int ok, const function<bool(int)> &discriminant) {
  ng--;
  while (ok - ng > 1)
    (discriminant((ng + ok) / 2) ? ok : ng) = (ng + ok) / 2;
  return ok;
}
```
