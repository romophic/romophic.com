## Purpose

Converts from base-n to base-m

## Usage

```cpp
string res = convNotation(str,n,m);
```

## Implementation

```cpp
string convNotation(const string &s, int from, int to) {
  int n = stoll(s, nullptr, from);
  if (n == 0)
    return "0";
  string result;
  while (n) {
    result += n % to < 10 ? '0' + n % to : 'A' + n % to - 10;
    n /= to;
  }
  if (s[0] == '-')
    result += '-';
  reverse(result.begin(), result.end());
  return result;
}
```
