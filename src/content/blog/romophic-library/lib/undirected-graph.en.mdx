## Purpose

重み付き無向グラフを扱う.

## Usage

### Declaration

```cpp
UndirectedGraph g(n);
```

### 重み付き無向パスの追加

```cpp
g.add(頂点, 頂点, 重み);
```

## Implementation

```cpp
class UndirectedGraph{
public:
  struct Edge {
    int u,v,cost;
  };
  const int n;
  vector<Edge> g;
  UndirectedGraph(int _n):n(_n){}
  void add(int u,int v,int cost){
    g.push_back({u,v,cost});
  }
};
```
