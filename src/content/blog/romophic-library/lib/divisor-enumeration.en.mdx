## Purpose

与えられた自然数の約数を列挙する.

## Time Complexity

$ O(\sqrt{n}) $

## Usage

例えば`divisor(12)`をすると, `vector<int>{1,2,3,4,6,12}`が返ってくる. 昇順であることが保証される.

## Implementation

```cpp
vector<int> divisor(int n) {
  vector<int> head, tail;
  for (int i = 1; i * i <= n; i++) {
    if (n % i == 0) {
      head.push_back(i);
      if (i * i != n)
        tail.push_back(n / i);
    }
  }
  head.insert(head.end(), tail.rbegin(), tail.rend());
  return head;
}
```
