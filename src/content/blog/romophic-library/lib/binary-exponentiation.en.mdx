## Purpose

Calculates $a^n \ \ (\text{mod}\ \ mod)$ in $O(\log(n))$.

## Time Complexity

$O(\log n)$

## Usage

`mop(a,b,mod)` returns $a^n \ \ (\text{mod}\ \ mod)$.

## Implementation

```cpp
int mop(int a, int n, int mod = LLONG_MAX) {
  int res = 1;
  while (n > 0) {
    if (n & 1)
      res = res * a % mod;
    a = a * a % mod;
    n >>= 1;
  }
  return res;
}
```
