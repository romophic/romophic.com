## Usage

Updates `a=max(a,b)` using `chmax(a,b)`. Returns true if an update occurred. `chmin` works similarly:

## Implementation

```cpp
template <class T>
bool chmax(T &a, const T &b) { return a < b ? a = b, 1 : 0; }
template <class T>
bool chmin(T &a, const T &b) { return a > b ? a = b, 1 : 0; }
```
