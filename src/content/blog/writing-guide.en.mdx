## 1. Post Metadata (Frontmatter)

At the top of each article, metadata (Frontmatter) is written in YAML format. Following the schema defined in `src/content.config.ts`, you can set the following attributes.

### Required Attributes

- **`title`**: The article's title. Used for page headings and OGP images.
- **`description`**: A summary of the article. Used for meta descriptions for search engines and preview cards in article lists.
- **`date`**: The creation/publication date of the article. ISO 8601 format like `YYYY-MM-DD` is recommended.

### Optional Attributes

- **`lang`**: `ja` or `en` (Default: `ja`). Used for multi-language support to explicitly state the article's language.
- **`tags`**: An array of tags indicating the classification of the article. Example: `['c++', 'algorithm']`
- **`authors`**: An array of author IDs. Corresponds to filenames defined in `src/content/authors`, rendering the author's name and avatar icon. Example: `['romophic']`
- **`image`**: The path to an eye-catching image specific to the article. If not specified, Astro will automatically generate a dynamic OGP image (including title and author) at build time.
- **`draft`**: If `true`, the post becomes a draft and is excluded from the production build.
- **`order`**: A numerical value explicitly controlling the navigation sequence to previous/next articles in subposts (hierarchical articles like series or books).

#### Concrete Example of Frontmatter

```yaml
---
title: 'romophic.com Writing Guide'
date: 2026-03-01T20:00:00+09:00
description: 'A concrete guide explaining writing rules and extended syntaxes for this site.'
tags: ['guide', 'markdown']
authors: ['romophic']
---
```

### Optimized Images with LQIP (Image Optimization)

By simply using the standard Markdown image syntax `![alt text](/path/to/image.png)`, the system internally lightens and optimizes the image into WebP format automatically.

At the same time, **LQIP (Low Quality Image Placeholder)** technology is applied. A low-resolution scaled-down image is swiftly layered underneath using CSS Grid and a blur effect, fading in seamlessly upon load completion so that no "Layout Shift" occurs.

## 4. Multi-language Support (i18n): How to Create English Articles

This site achieves completely bilingual EN/JA support (i18n) using static routing. To create an English translated article, follow these simple rules.

### 1. File Naming Rules (`.en.mdx`)

In the same directory as the Japanese main article, create a new file with the extension `.en.mdx`.

Example:
- Japanese Article: `src/content/blog/romophic-library/lib/binary-search.mdx`
- English Article: `src/content/blog/romophic-library/lib/binary-search.en.mdx`

### 2. `lang` Attribute in Frontmatter

In the Frontmatter of the created `.en.mdx` file, you must specify `lang: 'en'`.

```yaml
---
title: 'romophic.com Writing Guide: Markdown and Extensions'
date: 2026-03-01T20:40:00+09:00
description: 'A comprehensive guide to writing articles on romophic.com, including Frontmatter attributes and custom MDX extensions.'
lang: 'en'  # ← This is essential
tags: ['guide', 'markdown', 'mdx', 'astro']
authors: ['romophic']
---
```

The system will automatically strip the `.en` suffix, generating routing such that both Japanese and English correspond to the same URL slug (e.g., `/blog/binary-search` and `/en/blog/binary-search`).

## 5. Custom Integrations & "God-Tier UX" Architecture

This is the most critical feature defining this site as a technical digital garden: Interconnectivity.

### Bi-directional Links (Backlinks) and the Knowledge Graph

Whenever you insert a link to another article within the text, an immense backlink index is dynamically built by the system behind the scenes (time complexity $\mathcal{O}(N)$).

- **Simple Writing Rules**: Just write relative (or absolute) paths to related articles using standard link formats, as shown below.
  ```md
  [Title of another article](../other-post-id)
  ```
- **Automatic Display of Backlinks**: At the bottom of an article referenced as a target link, a `Backlinks` component stating "This article is linked from the following posts" is automatically generated.
- **Dynamic Reflection in the Knowledge Graph**: These connections uniquely appear as new nodes and traversing edges in the "Knowledge Graph", a physics-rendered D3.js network on the homepage background.

### Direct Import of MDX and Astro Components

Because we adopt the `.mdx` (Markdown + JSX) format, Astro/React components located under `src/components/` can be directly embedded into normal text.

**Usage Example:** When directly embedding the activity graph placed on the site into an article.

```mdx
import ActivityGraph from '../../components/features/ActivityGraph.astro';

<ActivityGraph />
```

With this functionality, you can write not just text, but interactive articles containing dynamic UI components or data visualizations.
