3 / 知識グラフ

トップページのグラフを、ここで触る

本物と同じ物理パラメータ（反発 −150・ばね 60・中心 0.15）とパレットで動く縮小再現です。ドラッグでノードを引っ張り、ホイールでズーム、ホバーで隣接ハイライト、クリックで遷移先を確認できます。

粒子が落ち着くまでお待ちください
ノードをクリックすると、本番での遷移先がここに表示されます

本物のパイプライン

  1. graph.json — ビルド時に全記事とタグ、内部リンクからノードとエッジを生成
  2. data.ts — 受け取った JSON を重複除去・双方向リンク整理・タグ色割当（純関数）
  3. manager.ts — fetch と初期化、Worker・描画・操作の配線
  4. physics.worker.ts — d3-force を Web Worker で実行（UIを固めない。タブ非表示中は自動停止、prefers-reduced-motion では静止）
  5. renderer.ts — Canvas 2D に毎フレーム描画（LOD でラベルを間引き）
  6. interaction.ts — drag / zoom / hover / click の配線

本物の設定値

linkDistance60
chargeStrength−150
centerStrength0.15
collideRadius15
hitRadius12
zoomExtent0.1 – 8
lodThreshold1.2

ノードの当たり判定は hitRadius をズーム倍率で割った画面上一定の半径、ラベルの表示は lodThreshold を超えたズームから。 このデモは同じ計算で動いています。

6 / ランタイム

ブラウザで起きること

静的とはいえ、読みやすさのための小さな JavaScript が動いています。開いて中身を確認できます。

テーマ切替と「チラつき」対策 AppScript.astro / ThemeToggle.astro

ページが最初に描画される前に、保存されたテーマ（またはOS設定）を読み取って data-theme を確定します。これがないと、ダーク設定なのに一瞬白い画面が出る「FOUC」が起きます。

切替の瞬間は .transition-none を付けて全トランジションを止め、色がじわじわ混ざるのを防ぎます。この文書の右上のボタンも同じ考え方です。

src/components/AppScript.astrodata-themetransition-none
ビュー遷移 — ページ間をSPAっぽく ClientRouter

Head.astro が <ClientRouter /> を読み込み、通常のリンク移動をフェード付きの遷移にしています。ポイントはライフサイクルイベントのペアです。

astro:page-load で「そのページ用の初期化」、astro:before-swap で「後片付け」を行います。この規律がないと、古いページのタイマー・Observer・Worker が残り続けます。

astro:page-loadastro:before-swapsrc/components/Head.astro
知識グラフの一生（初期化 → 破棄） GraphView.astro / manager.ts

GraphView.astro が astro:page-load で待機し、メインスレッドが空いたら（requestIdleCallback）グラフを初期化します。LCP を邪魔しないための遅延です。

ページを離れるときは astro:before-swap で manager.destroy() を呼び、fetch の abort・ResizeObserver / IntersectionObserver / MutationObserver の切断・Worker の terminate・requestAnimationFrame の取消をまとめて行います。破棄後に非同期処理が完了しても、destroyed フラグが再突入を防ぎます。

requestIdleCallbackdestroyed フラグAbortControllerworker.terminate()
目次（モバイルの進捗リング / デスクトップの追従） TOCHeader / TOCSidebar

見出しの位置は IntersectionObserver で追跡します。モバイルの TOC は円形の進捗リングにスクロール率を反映し、現在の見出しを自動でスクロール表示。カスタム要素なので、ページから外れたら disconnectedCallback でイベントと Observer を解放します。

IntersectionObservercustomElementsdisconnectedCallback
検索（Pagefind のコマンドパレット） SearchDialog.astro

検索は Ctrl/Cmd + K。ネイティブの <dialog> の中に Pagefind の UI を載せています。索引はビルド時に dist/pagefind/ として静的生成され、サーバー不要で動きます。

この文書でも似たものを実装しています。 Ctrl+K を押すと、この1ページ内を移動できるパレットが開きます。

Pagefindnative dialogCtrl+K
その他の小物 ScrollProgress / ScrollToTop / Giscus

ScrollProgress — ページ上端の細いバーで読書位置を表示。ScrollToTop — 記事末の「上へ」ボタン。Giscus — GitHub Discussions をコメント欄にする iframe（lazy 読み込み）。カスタム要素ではなく公式の client.js を astro:page-load（初回ロード＋全ナビゲーション後）で毎回注入し、discussion の term はスクリプト実行時の location.pathname から、テーマは注入時の data-theme から決まる（クライアント遷移で前の記事のスレッド・テーマになる競合を構造的に回避）。閲覧中のテーマ切替は公式の setConfig メッセージで live 更新。すべて小さな独立コンポーネントで、必要なページだけに載ります。
